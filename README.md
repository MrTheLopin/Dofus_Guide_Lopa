# Dofus Guide Lopa

Site communautaire interactif pour suivre les métiers et calculer la rentabilité de méthodes à kamas.

## Inclus
- 19 métiers et filtres par catégorie.
- Suivi du niveau 1–200 et paliers.
- Tableau de bord personnel.
- Calculateur : chiffre d'affaires, taxe HDV, coût, bénéfice net et K/h.
- Sauvegarde locale dans le navigateur.
- Méthodes et objectifs personnels.
- Responsive mobile/PC.
- Déploiement GitHub Pages automatique.

Les prix ne sont pas figés : chaque joueur saisit les prix de son serveur. Projet non affilié à Ankama.
